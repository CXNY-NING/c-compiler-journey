# 期望输出快照（golden）

`tests/run.sh` 将编译器生成的 `out.s` 与本目录下的同名 `.s` 逐字节比对。

## 快照性质

| 快照 | 来源 | 验证程度 |
|---|---|---|
| `input01.s` | 重构前的编译器输出 | 已确认为迁移前基线，迁移后逐字节一致 |
| `input02.s` | 当前编译器输出 | **基线快照**——仅保证输出稳定，尚未验证运行语义 |

> 重要：当前测试只能验证「生成的汇编文本不变」，**不能**验证「生成的程序运行结果正确」。
> 待引入 64 位工具链（MinGW-w64 / MSYS2 / Linux）后，应升级为端到端测试：
> 汇编 → 链接 → 运行 → 比对程序输出，并逐步用运行输出替换汇编快照。

## 更新 golden

确认新输出正确后，手动复制覆盖：

```bash
cp build/testout/out.s tests/expected/<name>.s
```
