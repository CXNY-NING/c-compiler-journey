# ACWJ 编译器手写学习仓库

**本仓库为个人学习记录仓库，非原创从零实现项目**

很喜欢 acwj 这个项目，所以搭建这个仓库，单纯用来记录自己的学习之路。我只是一名后辈学习者，在这里写下自己啃代码过程中的思考与收获。

本项目基于开源教程仓库 [DoctorWkt/acwj](https://github.com/DoctorWkt/acwj)，全程手动逐行抄写、调试、理解整套小型 C 语言编译器实现流程，用来系统学习编译原理：词法分析、语法分析、语义分析与代码生成。

所有基础核心逻辑均来自原作者教程，本人仅用于学习复盘，不用于商用，不冒充原创项目。

## 仓库定位说明

- **基础代码**：跟随教程手动复现，吃透递归下降编译器完整流程

## 目录结构

```
Sub_C/             主工作库：日常改代码全在这里
  include/         头文件
  *.cpp            源文件
  Sub_C.sln        Visual Studio 解决方案
legacy/            12 个章节快照（01scan … 11_FunctionsPart1），只读学习档案
tests/             回归测试：cases/（输入）、expected/（golden 快照）、run.sh
docs/              软件需求规格说明书、执行路线图、快速上手
build.sh           命令行构建（MinGW / GCC）
CMakeLists.txt     跨平台构建（CI / VS「打开文件夹」）
```

> 历史版本不再以「一章一个目录」的形式并列演进，而是收进 `legacy/` 归档，
> `Sub_C/` 成为唯一的活代码库。

## 快速开始

```bash
./build.sh              # 编译编译器 → build/cwj.exe
./tests/run.sh          # 跑回归测试

cd build && ./cwj.exe ../tests/cases/input01   # 生成 out.s
```

Visual Studio：打开 `Sub_C/Sub_C.sln`，选 `x64` + `Debug`，按 F5。

生成的 `out.s` 是 x86-64 GNU as 汇编，放到 Ubuntu 上：

```bash
gcc -o out out.s && ./out
```

**详细说明见 [docs/快速上手.md](docs/快速上手.md)**（含目录地图、构建方式、Ubuntu 验证步骤、已知缺陷清单）。
