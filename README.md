# ACWJ 编译器手写学习仓库
**本仓库为个人学习记录仓库，非原创从零实现项目**

很喜欢 acwj 这个项目，所以搭建这个仓库，单纯用来记录自己的学习之路。我只是一名后辈学习者，在这里写下自己啃代码过程中的思考与收获。

本项目基于开源教程仓库 [DoctorWkt/acwj](https://github.com/DoctorWkt/acwj)，全程手动逐行抄写、调试、理解整套小型 C 语言编译器实现流程，用来系统学习编译原理：词法分析、语法分析、语义分析与代码生成。

所有基础核心逻辑均来自原作者教程，本人仅用于学习复盘，不用于商用，不冒充原创项目。

## 仓库定位说明

- **基础代码**：跟随教程手动复现，吃透递归下降编译器完整流程

- **新增内容**：本人独立添加中文注释、学习笔记、BUG 修复

- **用途**：个人学习记录，实践编译原理相关知识

## 已学习 & 复现内容

完整跟随教程实现：词法扫描器、递归下降语法解析、运算符优先级、语句解析、变量系统、分支。项目仍在持续更新。

## 本人创新与优化点（后续计划，待实现）

区别于原教程代码，希望在完整学完原项目后，完成以下改进：

- 代码模块化重构，拆分词法/语法/语义/代码生成模块
- 完善中文注释，进一步提升代码可读性
